# Bubble Sort — TDD

Projeto Maven com Java 17 e JUnit 5.

O método `ordenar()` implementa Bubble Sort com trocas entre vizinhos e encerra quando uma passagem não faz trocas. Os três testes fornecidos passaram.

## Executar

```bash
mvn test
```

Consulte `REQUISITOS.md` para a descrição da atividade.

As execuções do ciclo estão em `ciclos-tdd.txt`.

A verificação de cobertura incluiu os testes complementares. O resultado de `mvn verify` foi de 4 testes aprovados e 100% de cobertura.
