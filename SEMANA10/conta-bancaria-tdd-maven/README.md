# Conta Bancária — TDD

Projeto Maven com Java 17 e JUnit 5.

## Executar
```bash
mvn test
```

## Prática
1. Execute os testes antes da implementação (RED).
2. Implemente o mínimo necessário.
3. Execute novamente até passar (GREEN).
4. Repita para o próximo comportamento.
5. Refatore mantendo os testes passando.

A suíte final passou com os quatro testes fornecidos. Os registros de execução estão em `ciclos-tdd.txt`.

A verificação de cobertura incluiu os testes complementares. O resultado de `mvn verify` foi de 7 testes aprovados e 100% de cobertura.
